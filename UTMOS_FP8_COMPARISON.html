측정 방법

  • 텍스트 코퍼스: LJ Speech metadata.csv (13,100 transcripts) 에서 random.seed(42) shuffle 후 char-length 30-300 필터로 500개 선별
  • 샘플 수: 100 프롬프트 (위 500 중 앞 100개) × 5 voices × 3 configs = 1500 WAV
  • Voices (5종): Vivian, Ryan, Aiden, Serena, Sohee — 중/영/한 화자, 남/녀, 다양한 톤
  • Configs:
    • Fork BF16: a5e1d5a0 (KV cache 토글 도입 시점, 다른 opt 모두 없음)
    • HEAD BF16: b0db844a (모든 opt 적용 후, FP8 없음)
    • HEAD + FP8: 위 + main talker FP8 (quantization: fp8)
  • UTMOSv1: utmos==1.1.10 Python 3.9 venv, sarulab MOSNet 기반
  • Paired analysis: 같은 (voice, prompt) 쌍의 score 차이로 quantization/opt 효과 isolation

결론

500 LJ Speech 프롬프트 × 5 voice 캐릭터에서의 1500-pair 평가 결과:

  • Fork → HEAD BF16: Δ = +0.009 → sub-talker 6단계 + post-merge 최적화가 quality 영향 없음 ✓
  • HEAD BF16 → HEAD FP8: Δ = +0.003 → main talker FP8 quantization이 quality 영향 없음 ✓
  • Fork → HEAD+FP8 (총합): Δ = +0.013 → throughput 1.75× 가속하면서 quality 손실 없음 ✓

1500-pair paired 비교에서 평균 절대 Δ 0.02 이내, 95% CI 모두 0 근접 → HEAD+FP8 production 안전.
